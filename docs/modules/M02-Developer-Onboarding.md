# Module M02 — Developer Onboarding

## Objective
Understand what developers build and what technical failure domains they encounter to personalize search and MCP retrieval.

## Onboarding Wizard Steps
1. **What do you build?** (Web, Mobile, Backend, AI / ML, DevOps, Cloud, Data, Open Source, Desktop, Security)
2. **What problems do you encounter?** (Debugging, Deployment, Architecture, Performance, Databases, APIs, Authentication, AI / LLM, DevOps, Security)
3. **Preferred Tools** (VS Code, Cursor, Kiro, Claude, ChatGPT, Other)

## JSON-Backend API Endpoints
- `POST /api/onboarding`: Saves user engineering preferences to `users.json`.
